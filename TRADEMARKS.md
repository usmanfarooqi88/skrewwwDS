# Trademarks and branding

The code in this repository is MIT-licensed (see [`LICENSE`](LICENSE)). The
**Skrewww** name, logo, wordmark, and visual brand identity are not.

This is a short, practical notice, not legal advice — formal trademark wording
may warrant later legal review.

## What you can do

The MIT license already covers this. You may fork the repository, modify the
code, build products on it, and redistribute it commercially — including
keeping the code's internal `skrewww-*` identifiers, CSS custom property
names, package/registry names as they appear in source, and factual statements
like "built with Skrewww" or "a fork of Skrewww."

## What the code license does not grant

Using the code does not grant permission to:

- Present a fork or derivative as the **official** Skrewww project, product, or release.
- Use the Skrewww name or logo as the name/branding of your own product, service, or company.
- Use the logo files in this repository (`public/logo.svg`, `public/light-logo.svg`, `public/dark-logo.svg`, `public/fav.svg`, `public/right-bottom-icon.svg`) as your own branding, or in a way that implies endorsement or affiliation.
- Imply that Skrewww endorses, sponsors, maintains, or supports your fork.

If you publish a fork, please rename it and replace the brand assets so users
can tell it apart from the official project.

## Commercial products

**Skrewww Pro** (the paid Figma library and Gumroad deliverables) and
**Skrewww Free** (the Community Figma file) are separate from this
repository's MIT-licensed code. Nothing here grants rights to redistribute
them. See [`docs/licensing.md`](docs/licensing.md).

## Questions

If you are unsure whether a particular use is acceptable, ask before shipping
it rather than assuming.
